Тестовый патч для исходной версии Space Studio.

Замените app.js в корне репозитория и добавьте рядом config.js из архива. Остальные файлы менять не нужно. Дождитесь публикации GitHub Pages и выполните жёсткое обновление страницы.

Токен автоматически подставляется из config.js. Подтверждение передачи токена выбранному Space оставлено. Значения вида hf_... скрываются в строках статуса приложения. Это не скрывает токен в исходниках или DevTools.

ВАЖНО: config.js содержит настоящий токен. Любой, кто имеет доступ к файлам сайта, может его прочитать и использовать вне приложения. Токен также останется в истории Git после удаления. После тестов отзовите его в настройках Hugging Face. Не используйте этот архив как публичный шаблон.

Кнопка очистки очищает токен только до перезагрузки. Для постоянного удаления очистите значение HF_TOKEN в config.js и отзовите токен на Hugging Face.

Этот патч изменяет только автоподстановку токена. Новый специализированный интерфейс image-to-image и debug-панель в него не входят. Старое описание хранения токена в README исходного проекта больше не соответствует этой тестовой сборке: вместо него применяются предупреждения этого файла и обновлённого диалога настроек.

Проверка: синтаксис JavaScript. Действительность токена и авторизованные запросы этим патчем не проверялись.
