# Space Studio

Личный статический веб-клиент Hugging Face Spaces. Русский интерфейс, адаптивная тёмная тема, поиск публичных Spaces, избранное, встроенный оригинальный интерфейс и прямой Gradio API. Без сборки, своего сервера и платных Inference Providers.

## Публикация на GitHub Pages

1. Создайте на GitHub публичный репозиторий, например `space-studio`.
2. Распакуйте архив. Загрузите **содержимое** папки `hf-studio` в корень репозитория через Add file → Upload files. `index.html` должен находиться прямо в корне, не внутри дополнительной папки. Загрузите также `app.js`, `style.css`, `gradio-client.js` и остальные файлы. Если скрытый `.nojekyll` не загрузился, для этого проекта это не критично.
3. Откройте Settings → Pages → Build and deployment → Source: Deploy from a branch.
4. Выберите ветку `main` и папку `/ (root)`, нажмите Save.
5. Дождитесь успешного развёртывания; GitHub покажет адрес сайта. Обычно это `https://ВАШ-ЛОГИН.github.io/space-studio/`.
6. Откройте адрес в современном Chrome, Edge, Firefox или Safari. Сервер и Node.js для работы не нужны.

Исходники опубликованного сайта видны посетителям. Никогда не вставляйте токен в код, README, коммиты или настройки репозитория. Это личный клиент без защиты самой страницы паролем: по ссылке её могут открыть другие, но они не получают ваш токен или избранное.

## Использование

- По умолчанию выбран `black-forest-labs/FLUX.1-schnell`.
- В режиме «Интерфейс Space» нажмите «Загрузить интерфейс». Здесь работает оригинальное приложение автора.
- В режиме «Прямой API» нажмите «Подключить API», заполните параметры и нажмите «Запустить». Форма строится по схеме конкретного Space, а не по заранее зашитым именам параметров.
- Для сложных компонентов есть JSON-поле; если формат непонятен, используйте оригинальный интерфейс. Полная совместимость со всеми компонентами и версиями Gradio не гарантируется.
- Изображения выводятся под формой. «Открыть / сохранить файл» открывает оригинал; сохраните его средствами браузера. Файлы не архивируются автоматически, а ссылки могут истекать.
- Поиск ищет по названию репозитория и показывает до 40 результатов. Это не семантический поиск и не подтверждение бесплатности.
- Можно вставить любой публичный ID `owner/space` или ссылку на Space. Закрытые/private Spaces через этот каталог не поддерживаются.
- Избранное хранится локально в браузере. Между компьютерами оно не синхронизируется. Кнопка копирования ссылки позволяет открыть тот же Space на другом устройстве.

## Авторизация и безопасность

Начните без регистрации и токена. Если API требует авторизации, создайте отдельный fine-grained токен на https://huggingface.co/settings/tokens с минимальными правами, необходимыми выбранному Space. Не используйте write-токен.

Токен вводится в «Доступ / токен» и остаётся в памяти вкладки. Он не записывается в localStorage, URL, код или избранное. История вызовов встроенного клиента Gradio отключена (`record_history: false`). Перезагрузка очищает токен. Кнопка удаления отключает текущий API-клиент.

Токен используется библиотекой Gradio для авторизации в инфраструктуре HF / выбранного Space. Подключайте его только к доверенным авторам и только на личном устройстве. Перед подключением с токеном приложение запрашивает подтверждение. Встроенный iframe не получает токен из настроек. Автоматическая передача OAuth-токена коду Space не реализована.

Это **не OAuth-вход в аккаунт**. Некоторые Spaces требуют именно входа через Hugging Face, согласия с условиями модели или отдельной авторизации. В этом случае откройте оригинальный Space в отдельной вкладке и войдите на стороне HF. Блокировка сторонних cookies может мешать входу внутри iframe.

Промпты, загружаемые файлы и результаты обрабатываются выбранным Space и инфраструктурой Hugging Face, а не локально на компьютере. Не отправляйте туда секреты. У клиентов Spaces разные политики хранения данных.

## Ограничения бесплатного доступа

Нельзя гарантировать доступ ко всем бесплатным генераторам без регистрации: автор может выключить API, отключить встраивание, включить платные функции, изменить интерфейс или удалить Space. У ZeroGPU бывают квоты, очередь и требования входа. Клиент не обходит эти ограничения, не дублирует Spaces и не запускает платное оборудование. Название или наличие публичного Space не гарантирует бесплатности его функций.

CORS, сетевые фильтры, спящий Space или ошибки сервера могут нарушать прямой API-вызов. Резервный способ — оригинальная страница. Статический GitHub Pages не может исправить серверные запреты и не хранит серверные секреты. Приложение требует интернет; офлайн-генерации нет.

## Локальный запуск (необязательно)

Из папки проекта выполните `python -m http.server 8000`, затем откройте `http://localhost:8000`. Не запускайте двойным кликом через `file://`: браузер блокирует ES-модули.

## Проверки этой сборки

- JavaScript прошёл синтаксическую проверку Node.js.
- В Chromium проверены загрузка настоящего Space FLUX.1-schnell и получение его API-схемы (6 параметров).
- Выполнена реальная генерация 512×512 через `/infer` **без токена**: получен один графический результат. Это подтверждает работу на момент проверки, а не постоянную доступность бесплатной квоты.
- Проверены сохранение избранного, отсутствие токена в localStorage и очистка токена после перезагрузки.
- При ширине 390 px горизонтального переполнения страницы нет. Ошибок JavaScript при проверке интерфейса не обнаружено.
- Другие Spaces, авторизованные вызовы, сложные загрузки файлов, отмена серверного вычисления и все браузеры отдельно не тестировались.
- На вашем GitHub Pages сборка ещё не опубликована; проверка проводилась на локальном HTTP-сервере с реальными сетевыми запросами к HF.

## Технологии и источники

HTML, CSS, JavaScript, локальный браузерный bundle `@gradio/client` 2.7.1. Никаких внешних скриптов с CDN во время запуска. Для обновления клиента нужно вручную заменить bundle и проверить совместимость.

- JS-клиент Gradio: https://www.gradio.app/guides/getting-started-with-the-js-client
- Встраивание Spaces: https://huggingface.co/docs/hub/spaces-embed
- ZeroGPU: https://huggingface.co/docs/hub/spaces-zerogpu
- Токены: https://huggingface.co/docs/hub/security-tokens
- Стартовый Space: https://huggingface.co/spaces/black-forest-labs/FLUX.1-schnell

Сторонние уведомления и лицензия Gradio приложены. Space Studio не является официальным продуктом Hugging Face или Gradio.
